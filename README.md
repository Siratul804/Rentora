# Rentora

### Multi-Tenant Rental Operations & On-Demand Service Dispatch Platform

Rentora is a **multi-tenant SaaS platform** for managing rental properties, tenants, leases, rent invoices, and maintenance requests in one centralized system.

It also provides a **service-provider dispatch system** for assigning plumbers, electricians, and other local service providers to maintenance requests.

## Key Features

- 🏢 Multi-tenant SaaS architecture
- 🔐 Role-Based Access Control (RBAC)
- 👑 Super Admin, Owner/Landlord & Tenant/Renter roles
- 🏠 Property and unit management
- 👤 Tenant and lease management
- 💰 Rent invoice and payment tracking
- 🛠️ Maintenance and service requests
- 🚚 Service-provider management and dispatch
- 💳 SaaS subscription management
- 🔒 Tenant and property data isolation

## Main Roles

| Role               | Access                                          |
| ------------------ | ----------------------------------------------- |
| **Super Admin**    | Platform, subscriptions & service providers     |
| **Owner/Landlord** | Properties, units, tenants, leases & invoices   |
| **Tenant/Renter**  | Rental information, payments & service requests |

## Objective

The goal of Rentora is to combine **rental property management and on-demand maintenance services** into a single, simple, and scalable SaaS platform.

## Technology Stack

- **Frontend:** Next.js
- **Backend:** Next.js API Route
- **Database:** MongoDB
- **Payment:** SSLCommerz
